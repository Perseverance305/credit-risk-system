# Credit Risk System

A production-inspired South African banking simulation that models the complete loan lifecycle from customer onboarding to credit risk assessment, affordability analysis, loan pricing, and IFRS 9 Expected Credit Loss (ECL).

## Objectives

This project is designed to demonstrate software engineering, data engineering, machine learning, and financial modelling skills through the development of a modular banking platform.

## Planned Features

- Customer Management
- Employment Profiles
- Financial Profiles
- Loan Applications
- Affordability Assessment
- Credit Risk Scoring (Probability of Default)
- Loan Pricing
- IFRS 9 Expected Credit Loss
- PostgreSQL Database
- FastAPI REST API
- Docker Deployment
- Streamlit Dashboard

## Technology Stack
